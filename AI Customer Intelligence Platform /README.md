# AI Customer Intelligence Platform

An end-to-end lightweight AI customer intelligence platform combining:

- Customer data analysis
- SQL analytics
- Customer churn prediction
- Explainable AI
- Customer-support NLP
- Semantic search
- FAISS vector search
- Retrieval-Augmented Generation (RAG)
- Local small LLM
- Tool-based AI workflows
- Flask web application

## Objective

The system transforms customer data into actionable customer insights while remaining lightweight enough to run locally on a low-end laptop.

## Main Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- NLTK
- Sentence Transformers
- FAISS
- Flask
- SQLite
